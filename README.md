## 📚 Conteúdo
 
### 🔰 Introdução ao Python
 
Fundamentos da linguagem com exemplos práticos e isolados por tema.
 
**Operadores**
- Aritméticos, de atribuição, comparação, lógicos, identidade e associação
**Estruturas Condicionais**
- `if`, `elif`, `else`, `if` aninhado e operador ternário
**Estruturas de Repetição**
- `while`, `for`, `range()` e comando `break`
**Manipulação de Strings**
- Interpolação de variáveis (f-strings), fatiamento, `strip`, `upper`, `lower`, `title`, `center`, `join`
**Estruturas de Dados**
 
| Tipo | Métodos estudados |
|------|------------------|
| **Listas** | `append`, `extend`, `insert`, `remove`, `pop`, `clear`, `copy`, `sort`, `sorted`, `reverse`, `count`, `index`, `len`, compreensão de listas, listas aninhadas |
| **Dicionários** | `get`, `pop`, `popitem`, `clear`, `copy`, `update`, `setdefault`, `fromkeys`, `keys`, `values`, `items`, operador `in`, dicionários aninhados |
| **Tuplas** | Criação, acesso e imutabilidade |

### 🧱 Python Orientado a Objetos
 
Estudo completo dos pilares da POO com exemplos hands-on.
 
**Classes e Objetos**
- Criação de classes, instâncias e atributos
- Exemplo prático: classe `Bicicleta` com métodos `buzinar`, `parar` e `correr`
**Construtores e Destrutores**
- Método `__init__` e `__del__`
**Encapsulamento**
- Atributos privados com convenção `_` e `__`
- Uso de `@property`, getters e setters
**Herança**
- Herança simples e múltipla
- Uso de `super()` e `**kwargs` para cadeia de herança
- Resolução de método com `__mro__`
- Exemplos: `Animal → Ave / Mamifero → Ornitorrinco`
**Interfaces e Classes Abstratas**
- Módulo `abc` com `ABC` e `@abstractmethod`
- Atributos de classe vs. atributos de instância
- Métodos de classe (`@classmethod`) e estáticos (`@staticmethod`)
**Polimorfismo**
- Sobrescrita de métodos em subclasses
- Exemplo com `Passaro → Pardal / Avestruz`

## ▶️ Como usar
 
1. Clone o repositório:
```bash
git clone https://github.com/pesouzaaa/estudos-em-python.git
```
 
2. Navegue até o arquivo que deseja estudar e execute:
```bash
python nome_do_arquivo.py
```
 
Não há dependências externas — apenas Python 3 instalado é suficiente.
